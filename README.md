# صائد النجوم (Star Catcher)

لعبة خفيفة جداً مبنية بـ **Flutter** بنفس هيكل مشروع «الكوابيس»: حرّك السلّة بإصبعك والتقط النجوم ⭐ وتجنّب القنابل 💣.

- **الحزمة:** `com.starcatcher.game`  •  **الإصدار:** 1.0.0+1
- **صورة غلاف واحدة صغيرة فقط** (`assets/cover.png`) وبلا أصوات، وكل شيء داخل اللعبة مرسوم بالكود فحجم الـ APK صغير.
- **أفضل نتيجة** تُحفظ بـ `shared_preferences`.

## اللعب
- 3 قلوب. القنبلة أو تفويت نجمة يكلّفك قلباً.
- السرعة وعدد القنابل يزدادان مع نتيجتك.

## تصحيحات مأخوذة من فحص مشروع الكوابيس
- حُذفت صلاحيات الشبكة (لعبة فردية لا تحتاجها)، واتجاه الشاشة عمودي.
- حلقة اللعب بـ `Ticker` مع سقف للزمن (`dt ≤ 0.05`) وإيقاف الـ Ticker في `dispose` كما في الكوابيس، والرسم بـ `CustomPainter`.

## البناء
ارفع المجلد إلى GitHub (فرع `main`) فيعمل `.github/workflows/main.yml` وينتج `app-release.apk` من Actions ← Artifacts.

## ملاحظة
لم يُبنَ المشروع ولم يُشغَّل قبل تسليمه (بيئة الإنشاء بلا Flutter)، والكود مراجَع يدوياً. أرسل سجل البناء إن ظهر خطأ.
